# 规则线手册

先读[公共手册](common.md)。本手册只写规则线的差异，杭州麻将规则与计分见[平台规则](../../../../docs/reference/platform.md)。

## 本线参数

| 项目 | 内容 |
|---|---|
| 可以修改 | 只有 `rule/`（主要是 `rule/strategy.py`）。v0 是最朴素的牌效策略，只看向听和进张 |
| 尝试命令 | `python -m harness.evaluate rule "<改动>" --design-start <epoch>`：冻结 `rule/`、评估，最后打印汇报块 |
| 目标 | 从规则的第一性原理出发，覆盖全部观察和动作空间，做出尽可能强的规则策略。大方向是速度优先、必胜时追求翻倍，整体上不防守。自动研究的分支都从同一个初始策略演化而来，视野偏窄；这条线要有意尝试它们没用过的观察和动作。对手池成员的源码可以参考，但不照搬 |
| 时限 | 策略的算力不设上限，但正式比赛是多桌并发，出牌 2.0 秒、应答 0.6 秒不能超。超时由平台默认动作代打，代价直接算进分数 |
| 主机 | 只在 Mac 本机评估 |
| 回退 | `restore rule` 用当前最好尝试的冻结包（`.local/attempts/<编号>/package`）覆盖 `rule/` |

## 起步

规则线没有额外的起步步骤。第一次尝试就是 v0 原样，它没有可比的冠军，跑完评估阶梯后直接成为规则线的最好版本。

## 自由对战上场版本

- 用户要求：自由对战自动换上最强的版本。两条线都对同一个固定对手池计分，分数可以直接比较。上场版本由本线会话负责切换。
- 常驻脚本是 `.local/competition/free_play_strongest.py`。它优先使用 `.local/competition/entrant.pin` 里写的研究候选。
- 还没有实现让 firstprinciples 的尝试上场。等任一条线出现确认成功、并且分数高于参照线的版本，再实现并切换，切换前先告诉用户。
  - 规则尝试的冻结包在 `.local/attempts/<编号>/package`。
  - RL 尝试的模型按权重 sha 存在 Mac 的模型库里。
- 这部分工作不算一次尝试。
