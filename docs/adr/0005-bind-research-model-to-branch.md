# 研究模型绑定分支，显式记录后期切换

> 周期屏障、保护淘汰或模型切换时机以 [ADR-0006](0006-decouple-strategy-history-from-experiments.md) 为准；框架默认阵容与当前项目配置见[研究手册](../reference/strategy-agent.md)，不以本文历史默认值为准。本文保留当时取舍，组合身份、训练和分支隔离约束继续适用。

前期研究模型固定绑定研究分支，以便解释不同策略组合与研究模型的长期表现。充分收敛后，用户可视情况统一切换为较强模型；切换必须保留原研究谱系，并作为明确历史事件记录，不能把跨模型成果全部归于切换后的模型。不在前期实现自动收敛判断或自动模型升级。

推理等级按模型声明的范围校验，Astra 默认 medium，DeepSeek 支持 low/high/max 且默认 max，Qwen 支持 max 且默认 max。不得静默映射不支持的等级；本地模型声明不等于已完成网关运行验证。

每个组合默认三个分支，分别是一支 Astra、一支 DeepSeek 和一支 Qwen，可配置。相同组合的分支共用初始模板，不额外强制不同研究假设、参数或实现变体；后续探索差异来自各自独立的 Agent 研究过程。Agent 可以查看其他分支的公开成绩，但仅能读取、派生本分支的源码与模型。
