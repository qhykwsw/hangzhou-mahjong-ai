# 维护者亲自迭代的规则线与 RL 线

2026-09-24 决定。

自动研究的规则分支经过几百轮迭代后收益已经很小，最近还出现了倒退。18 个历史冠军的大乱斗显示，结构最简单、专注于「速度优先、必胜时追求翻倍」的版本最强，而层层叠加修正的分支掉到了中游。所有分支都继承同一个初始策略，研究 Agent 受它影响很大，很多观察和动作空间从来没有尝试过，只在细节上反复微调。

## 决定

- 新建人工项目 `projects/personal/firstprinciples/`，由维护者（本项目中是 Claude 本人）亲自推进两条迭代线：规则线从最朴素的牌效策略起步、按杭州麻将规则的第一性原理逐步扩展；RL 线沿用训练方案框架，由维护者修改训练方案。迭代方式参照 autoresearch：每次只改一处、固定预算评估、每次尝试都记录、只继承成功的尝试、不设终点。
- 评估不走研究框架。每次尝试面对同一个固定对手池（6 个最强且风格各异的规则版本加一个模仿模型），每局被评估版本坐一个座位，其余三座从对手池取三个，阵容与座位按固定顺序轮换。得分是它对对手池的场均桌面分，两条线的得分可直接比较。
- 为避免反复在同一批牌局上挑选造成高估，评估分开发集与确认集：日常尝试在固定的开发牌局上按 4096 → 8192 → 16384 场的阶梯判定，明显落后即停；开发集得分超过当前最好成绩后，再在全新牌墙上与最好版本各打一遍做配对确认，单侧 90% 下界大于 0 才算成功。
- 评估时限收紧到出牌 2.0 秒、应答 0.6 秒，超时按平台默认动作代打，策略算力不另设上限，超时代价直接体现在得分里。
- 自迭代阶段追求迭代效率：两条线的每次尝试都用同样小的固定预算（RL 线每次训练 1 小时，起点模型的模仿训练也只给 1 小时），只比较相对提升；找出有效的改动后，再另行放大规模训练。
- 研究实验保持暂停，状态与历史不动。

## 考虑过的替代方案

- 在研究框架里新开分支：框架的评估对手、晋级与大乱斗节奏为多个 Agent 分支并行设计，套用本方案等于改框架协议。
- 每次尝试都换新牌墙并重打最好版本：不存在选择偏差，但每次尝试的成本翻倍；开发集加确认集只在少数成功尝试上付这笔成本。
- 与各对手逐一单挑：可以测出正面交锋的强弱，但与平台比赛「一人面对三家」的形态不一致。
