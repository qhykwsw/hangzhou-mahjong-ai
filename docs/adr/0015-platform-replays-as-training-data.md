# 平台对局牌谱作为训练数据

2026-09-24 决定。

此前项目规定外部对战与研究训练隔离：测试房、自由对战和正式比赛的记录只用于平台运行与框架审计。这条规定本意是保证评估可复现，并防止策略在决策时读到不该读的信息，但它连带放弃了唯一能反映平台真实对手的数据。自由对战的分析显示，本地共同大乱斗的冠军在平台对手池里只是中游：本地评估只在自家分支之间比较，没有外部风格的对手。

平台为自由匹配房和测试房提供赛后完整牌谱（四家起手牌、全部摸打吃碰杠、应答与超时），接入指南明确说明用于离线复盘与算法优化。我们在对局中本来就会拉取并保存这些牌谱。

## 决定

- 我方参加的自由对战与测试房牌谱可以作为训练数据。人工自我对弈项目的规则教师路线（`projects/personal/selfplay/guided/`）用它模仿平台上的强对手，也可以用它训练代表平台对手池的模型，作为本地评估的固定对手。
- 牌谱在本地引擎里逐手重放还原成合法观察：只记录决策方座位当时能看到的信息，动作标签是该玩家在平台上的实际动作。隐藏牌只用来驱动重放，不进入任何决策输入。重放必须和平台完全一致：每次摸牌、每个动作的合法性、每手结算和整场总分都要对上，任何一处不一致，这一场整场丢弃。
- 平台代打的超时动作不是玩家自己的选择，默认不作为模仿标签。
- 训练使用的牌谱按文件哈希冻结进训练清单，随实验保存。评估条件的冻结规则不变：新的对手模型或新一批数据进入评估，要开新的评估版本或新实验。
- 正式锦标赛没有赛后牌谱接口，只有我方座位的实时事件，不用于还原对手决策。
- 自动研究的候选目前仍不读取平台记录。研究 Agent 接收平台对局统计或复盘材料需要修改研究 MCP 的接口，将另行决定。

## 考虑过的替代方案

- 继续隔离、只用自家对局：本地冠军在平台上只是中游，已经说明这样不够。
- 直接用平台实时快照训练：只有我方座位的信息，拿不到对手的决策；赛后牌谱信息完整，且平台明确允许用于算法优化。
- 直接存编码好的训练张量：重放和编码很快（600 场约 20 秒），只保存牌谱和冻结清单，训练时在目标机现场还原，编码与训练、推理同源，也不需要在机器间传输大文件。
