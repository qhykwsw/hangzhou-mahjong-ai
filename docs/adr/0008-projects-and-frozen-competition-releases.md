# 以策略项目和冻结发布版本承载多种开发方式

项目同时支持自动研究和人工维护的算法方向。共享引擎、规则、SDK、比赛和平台能力继续位于根目录；每个算法方向成为独立策略项目，由 `project.toml` 声明入口、依赖和构建方式。自动研究集中在一个 `agent-research` 项目中，人工 PPO、规则或搜索分别拥有自己的项目生命周期，不强制进入研究状态机。

所有跨项目比赛只接收不可变的冻结发布版本。发布版本以项目版本号和内容哈希标识，注册后可以成为只参赛对象或经用户明确加入的常驻对手，但永远不会因注册自动成为迭代对象。比赛注册表与自动研究的 `research.sqlite` 分离；排行榜绑定实际比赛条件和参赛集合，撤销注册只影响未来比赛，不改写历史结果。

当时目录重组的迁移要求是保留实验、分支、候选、回执和暂停恢复状态，由受控工具原子复制、校验冻结工件、重写路径引用并验证恢复；失败时保留原目录不变。这是历史目录迁移约束，不代表当前支持旧协议迁移或跨操作系统续跑；现行初始化与发布流程见[策略项目](../reference/projects.md)。
