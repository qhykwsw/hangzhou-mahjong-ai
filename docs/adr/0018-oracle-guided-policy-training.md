# 人工自我对弈项目的策略网络可在训练中读取隐藏状态（oracle guiding）

ADR-0009 只允许价值网络在训练进程内读取隐藏状态，策略网络始终只读合法观察。2026-10-07 用户放开这一限制：人工自我对弈项目的策略网络可以在训练进程内读取隐藏状态（三家暗手、牌墙），做法是 Suphx 式 oracle guiding。

具体做法：Actor 增加 oracle 输入通道，零初始化；训练中按保留率 γ 随机遮盖 oracle 输入，γ 从 1 逐步衰减到 0，让策略逐步学会不依赖隐藏信息。

约束不变的部分：
- 发布包、自由对战、正式比赛与所有评估中的推理只读合法观察。
- 导出时剥离 oracle 通道；γ=0 的网络与剥离后的网络逐位一致，导出前要核对。
- 推理服务拒绝带 oracle 通道的模型。

这样做的原因：公开文献里少数确认有效的麻将 RL 做法之一就是 oracle guiding（Suphx）。仅用合法观察时，我们的一步改进普查显示余量约为零；完美信息下的上界约每场 11 分。oracle guiding 是把这部分信息转成可发布策略的已知途径。

自动研究候选不受此 ADR 影响，「策略训练只接收合法观察」对它们继续成立。

考虑过的替代方案：
- 只用 oracle 辅助头。039 已试过，无效。
- 把 oracle 信息只给价值网络，这是 ADR-0009 的现状，已用到平台。
