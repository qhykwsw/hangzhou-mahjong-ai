# 周期内冻结参照并配对评估，周期末同步结算

> 周期屏障、保护淘汰或模型切换时机以 [ADR-0006](0006-decouple-strategy-history-from-experiments.md) 为准；本文保留当时取舍，组合身份、训练和分支隔离约束继续适用。
> 排名与选优口径以 [ADR-0010](0010-table-score-as-primary-evaluation-metric.md) 为准：场均桌面分取代下文的平均名次效用。

每个淘汰周期从分支现役代表构建冻结参照池，各分支使用覆盖不同策略组合的固定对手样本，每轮更换评估牌局，现役代表与本轮候选共享相同对手版本、初始牌局及座位安排。比较前后改动无需穷举所有历史版本；配对减少评估噪声，但不保证有限样本能分辨所有微小改进。

周期内分支异步完成迭代，达到轮数终点的分支等待其余存活分支，全部完成后统一结算、淘汰并更新参照池。默认首周期二十轮、后续每周期十轮，参数可配置；接受快分支在边界等待的代价，以使慢算法获得相同轮数的探索机会。

Agent 使用动态并发槽位，提交后释放槽位，训练和评估使用独立资源配额。

每个分支保留评估选出的最优版本作为现役代表。Agent 可以读取本分支全部历史，并从任意本支历史版本继续修改；派生起点与现役代表分别记录，不强制研究只沿现役代表推进。比较基准是现役代表，即使候选从其他历史版本派生也不改为仅比较该历史版本。

所有准备成功的候选和现役代表均完成同等规模的完整配对评估，不提前筛选，不根据中间成绩追加样本，也不另设确认赛。样本规模可配置，默认值根据实际对局吞吐与方差校准。

周期末每个分支派出现役代表，冻结阵容并进行出场均衡、对手组合多样和四座轮换的抽样竞技，按本周期平均名次效用排名。Elo 若实现仅辅助展示，不决定淘汰。只检查排名最后 floor(存活分支数 × 淘汰比例) 个分支，默认比例 20%；触发组合最低存活数保护时跳过，不向前递补淘汰名额，因此实际淘汰可以为零。每个组合默认至少保留两支，参数可配置。

共同排行榜在每个淘汰周期的共同竞技期间更新，不为实时展示额外插入轻量竞技。周期内可持续更新研究进度和候选记录，但不得把不同对手样本下的分支内改进量当作共同竞技排名。
