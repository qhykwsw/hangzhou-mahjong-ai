# ADR-0010：评估与优化主口径改为桌面分

## 状态

已接受（2026-09-18）

## 背景

平台非决赛阶段按总分、名次分、白板获取数、稳定身份依次排序，决赛按总分。每个阶段每人固定 10 场，一场 16 或 8 局，所以参赛目标就是在固定局数内把分数打到最高。

此前自动研究的选优主口径、轮末共同竞技排行榜、跨项目共享比赛的 `standings`，以及策略 SDK 的训练奖励，用的都是每场名次效用（4−名次）。名次口径把大分第一名和小分第一名视为等同，与第一排序键不一致：在 16384 场同一批对局上，两种口径对 12 个参赛者排出的顺序有 6 对相反（Kendall tau 0.818），其中三个内置启发式的名次效用高于强化学习版本，桌面分却更低。人工自我对弈项目一开始就按桌面分训练与评估，两条线的口径也因此不一致。

## 决定

- 场口径主判据改为场均桌面分；同分时用场均名次分（+3 / +1 / −1 / −3，同分取平均），与平台排序一致。名次效用与逐局读数保留为对照，不参与排序与晋级。
- 候选晋级仍用同一副牌、同一对手的配对差双侧 95% Student-t 区间，但配对量改成桌面分（`field_score_group_means`）。
- 策略 SDK 的训练奖励改为桌面分；`Recipe.reward_scale` 默认值从 1.0 改为 8.0，让奖励以一次闲家自摸（8 倍底分）为单位，量级与旧的名次效用相当。
- 跨项目共享比赛把分数与逐局增量交给 `standings`，排行榜按分数排序。

## 影响

- 评估口径属于研究协议，按 AGENTS 只能在新实验生效。运行中的实验用自己冻结的运行时，读数与晋级行为不变；缺少分数块均值的旧回执，主口径自动回退到它原本的名次效用。
- 各分支的累计结论是在名次口径下攒的，换口径后现役代表可能变化，迭代交接需要说明这一点。
- 判别力口径见 `runs/stability/summary.md` 的实测：固定对手模式下两策略差的标准误约 39 / √场数，1024 场可判 1.7 分。
