# 规则与强化学习统一为研究分支，共同大乱斗取代研究轮次

2026-09-23 决定。取代 [ADR-0012](0012-recipe-iteration-for-rl-training.md) 中“方案迭代独立于规则自迭代运行”的部分，以及研究轮次（固定次数迭代 + 轮末大乱斗）的做法。

规则自迭代和训练方案迭代原本是两套系统：规则分支按轮次各迭代 3 次后统一大乱斗；方案线用旧规则包当冻结对手，独立晋级。两边的对手互不相通，RL 一直对标旧版本规则；规则分支也从不面对 RL 模型。轮次同步还让快分支等慢分支。改为一个研究分支注册表：

- **分支种类**：策略分支的候选是规则代码；方案分支的候选是训练方案，由它从固定起点训练出的模型参赛。两者共用现役代表、研究判断、累计结论、晋级、评估对手、共同大乱斗与排行榜；候选如何产出、在哪台主机执行、评估场数分别保留。
- **连续迭代**：取消研究轮次与每轮固定迭代次数，每个分支完成一次迭代就开始下一次，直到手动暂停。
- **评估对手**：最近一次共同大乱斗排名前三的非锚点版本，在一次分支迭代开始时冻结。可以包含本分支自己的版本，也可以是 RL 模型。
- **分段配对评估**：策略分支每边 1024 → 2048 → 4096 场，方案分支每边 4096 → 8192 → 16384 场，累计计数。前两段用 99% 区间，下界 > 0 提前晋级、上界 < 0 提前淘汰；最后一段用 95% 区间，下界 > 0 才晋级。多次看数据会放大假晋级率，前段收紧阈值来抵消。
- **共同大乱斗**：所有活跃分支的现役代表，加参照锚点（方案分支的模仿起点），每个出场 8192 次。累计 4 次晋级后发起；有晋级在等且距上次超过 12 小时也发起。1024 次出场的区间约 ±3.5 分，比分支间差距还大，不足以稳定选出前三。
- **主机分工**：Mac 是唯一控制面，运行策略分支的研究模型与评估；4070 执行方案分支的训练与评估；4090 训练模仿起点并执行共同大乱斗，大乱斗优先于模仿（模仿存检查点暂停，跑完续训）。
- **统一对局框架**：规则座位按各自冻结运行时在独立进程中运行，跨实验延续的旧版本照常同场；模型座位通过本机唯一的批量推理服务出招（Mac 用 MPS fp16，台式机用 CUDA），评估 worker 共享它以攒批。
- **实验**：保留，表示一套冻结的框架协议（引擎运行时、评估规则、计分口径）；协议改变即开新实验，分支历史延续。
- **研究模型**：原有四个规则分支继续用 deepseek；新增牌效、番型各一条 gpt-6-astra（high）分支，从初始启发式基线从零开始；方案分支用 gpt-6-astra（high），思考时限 10 分钟。
- **方案分支固定条件**：起点是 4090 模仿阶段的甜点快照（大模型，固定不动），训练最长 4 小时，方案可提前结束，只比较最终强度；训练对手由方案决定，默认用评估对手；第 0 版是 ADR-0012 的多步小步策略梯度基线训练 4 小时的产物，不附带当时的起点诊断。

## Consequences

- Mac 需要 torch（仅用于模型座位推理服务）；自我对弈项目 `src/` 仍不得引入 torch，因为它随比赛发布包分发。
- 方案分支的评估对手可能来自不同运行时的规则版本，训练采集同样要支持按运行时隔离的规则座位。
- 旧的研究实验（第 40/50 轮）与旧方案实验直接结束；规则分支的历史与现役代表延续到新实验。
