# 人工自我对弈项目使用独立训练器、非对称价值网络与 ONNX 推理

人工策略项目 `projects/personal/selfplay/` 的目标是训练一个在官方赛制下最大化阶段总分的对局策略模型。它的训练器直接驱动引擎的 `HandState`，不经过候选运行时的沙箱通道：价值网络在训练时读取三家手牌与牌墙构成，策略网络只读取合法观察。这样做是因为非对称 critic 是不完全信息博弈里降低价值估计方差的主要手段，而候选运行时按设计只发送公开观察。隐藏信息只进入价值头，不进入策略头，不进入任何发布产物；`AGENTS.md` 中“策略训练只接收合法观察”的约束对自动研究候选继续成立，本项目是显式的例外。

训练用 PyTorch，发布用 ONNX Runtime。发布包依赖 `onnxruntime`，在现有沙箱里 CPU 单线程推理，发布、注册、本地互打、平台对战全部沿用现有工具链。不为本项目另开平台对战通道：实测单样本推理 GPU 没有优势，而第二条推理路径会带来训练与部署不一致的风险。导出后必须比对 PyTorch 与 ONNX 的输出一致，并在真实沙箱里跑一次构建探针。

考虑过的替代方案：让 critic 也只看公开信息（放弃方差收益）；发布包携带 torch CPU wheel（体积逼近上限、16 桌各自导入内存重）；训练期也通过候选运行时（每步进程间通信，吞吐下降一个数量级）。
