# 迭代规范以倾向表达，不给改动幅度和停滞设口径

分支迭代需要两条行为倾向：每个候选只承载一个可单独证伪的假设、让复杂度随迭代增长；连续多次没有产生更好代表时，放弃单点归因的整体改动是正当手段而非例外。这两条只写进研究契约，由研究 Agent 自行判断改动幅度、破局时机与是否说明，框架不度量改动规模、不设停滞次数阈值、不因改动过大拒绝提交。

探索方式与统计晋级分别约束。此前关于“不增加显著性门槛”的取舍已由现行[配对置信区间晋级规则](../reference/strategy-agent.md#成绩历史与恢复)替代，普通候选与破局候选都须满足同一证据门槛；这不改变 Agent 对改动幅度的判断权。

选择倾向而非口径，是因为改动幅度只有相对分支自身轨迹才有意义，同一处改动在起步阶段可能已经是整体性调整，到成熟期只是常规幅度；把探索自由交给 Agent 本身就是这项研究的意义，规范要治的是无意识的大杂烩，不是大改。代价是遵守与否没有自动信号：判断与假设写在计划、候选记录和网页卡片上，由用户阅读验证，不依靠框架度量改动幅度或停滞次数。
